Buek Copilot — Privacy Policy

Last updated: 3 August 2026
Product: Buek Copilot (Custom GPT) for Buek Core / abdularief23/buek-core

Ringkas: Buek Copilot menggunakan GitHub API (read-only) untuk membaca repository publik/privat Anda berdasarkan token yang Anda konfigurasi sendiri. Percakapan diproses oleh OpenAI sesuai kebijakan OpenAI. Kami tidak menjual data pengguna.

1. Siapa yang bertanggung jawab

Kebijakan ini berlaku untuk Custom GPT “Buek Copilot” yang dikonfigurasi oleh pemilik proyek Buek Core. Kontak: info@buekwebsite.com.

2. Data yang diproses

  • Pesan chat yang Anda kirim ke Buek Copilot (diproses oleh OpenAI).
  • Permintaan ke GitHub API yang dibuat Action GPT (path file, nomor PR, query pencarian, dll.).
  • Personal Access Token (PAT) GitHub yang Anda masukkan sebagai secret di GPT Builder — disimpan oleh platform OpenAI sesuai konfigurasi Action Anda; tidak disimpan di server Buek Core.

3. Layanan pihak ketiga

  • OpenAI / ChatGPT — platform Custom GPT. Lihat: OpenAI Privacy Policy.
  • GitHub API (api.github.com) — Action read-only untuk membaca isi repository, PR, dan commit. Lihat: GitHub Privacy Statement.

4. Tujuan pemrosesan

Memberikan jawaban arsitektur/review berdasarkan isi repository terbaru (docs, PR, commit) tanpa mengunggah dokumen secara manual setiap kali berubah.

5. Apa yang tidak kami lakukan

  • Tidak menulis, menghapus, atau menggabungkan kode di GitHub melalui Action (read-only).
  • Tidak menjual atau menyewakan data chat.
  • Tidak meminta Anda menempelkan PAT di dalam percakapan chat.

6. Retensi

Retensi percakapan mengikuti pengaturan akun ChatGPT / OpenAI Anda. Data di GitHub tetap berada di GitHub sesuai kebijakan GitHub dan pengaturan repository Anda.

7. Keamanan token

Gunakan Fine-grained PAT dengan izin baca seminimal mungkin (Contents, Pull requests, Metadata). Rotasi token secara berkala. Cabut token jika bocor.

8. Perubahan

Kebijakan ini dapat diperbarui. Versi terbaru dipublikasikan di URL ini dan/atau di repository docs/mygpt/PRIVACY_POLICY.md.

9. Kontak

Pertanyaan privasi: info@buekwebsite.com
